# SMU public site reference

> **Provenance, not current product scope.** This is a capture of the public SMU site on 2 November
> 2026. The design system in [`../DESIGN.md`](../DESIGN.md) is normative for the product; where this
> document conflicts (for example the card-radius note below), follow DESIGN.md. The marketplace and
> news-hub surfaces referenced by the capture are no longer in the app.

Reference capture for the **SMU Circular Coffee** redesign. The live site was crawled on
2 November 2026 from `https://www.smu.edu.sg`. All screenshots, raw computed styles and
the complete link inventory are kept in the project workspace's `.scratch/smu-reference/`.

## What was captured

- **37 pages** across the main navigation, screenshotted at 1440×900
  (full-page) plus a homepage fold, homepage mobile and the menu/search overlays.
- **234 public internal URLs** after removing Incapsula challenge URLs,
  duplicates, query strings and static assets.
- **Computed design tokens** in `inspect.json`: fonts, sizes, colours, section
  backgrounds, header/footer HTML and measured element boxes.
- **Full text** for each captured page in `text-*.txt` and the rendered homepage in
  `home.html`.

## Notes and limitations

- `smu.edu.sg` is protected by Imperva. Direct asset downloads need browser cookies;
  the capture scripts use Playwright with a real Chromium context.
- A few pages returned no internal links or an empty title during the crawl
  (`/research/digital-transformation`, `/information-for/students-and-alumni`,
  `/information-for/faculty-and-staff`, `/information-for/suppliers/...`). Their
  screenshots are still included where the page rendered.
- Link discovery is breadth-first from the captured pages, not an exhaustive crawl of
  every department subdomain. External SMU subdomains (news, admissions, giving, schools)
  are represented in the footer and navigation but live on their own domains.
